ZENITH SURVEYING & ENGINEERING - WEBSITE PACKAGE
=================================================
Upload the CONTENTS of this folder (index.html, favicon.ico, robots.txt,
sitemap.xml and the assets/ folder) to Netlify. index.html must be at the
top level with assets/ beside it.

FORMS (Netlify Forms, built in, no signup needed)
Two forms are wired for Netlify: "quote" (contact page) and
"job-application" (careers, with CV upload). After your first deploy:
  Netlify dashboard -> your site -> Forms  : submissions appear here.
  Forms -> Form notifications -> Add notification -> Email notification
  and enter info@zenithspatial.com so every submission is emailed to you.
Do this for both forms. Free plan: 100 submissions/month.

MAP
The Location section uses a live Google Maps embed. It only loads on a
real web address (not when opening index.html from your computer).
